## Concepts clés que vous apprendrez

- **Ensemble de données**: Collection de points de données utilisés pour l'entraînement
- **Caractéristiques**: Variables d'entrée (X) utilisées pour les prédictions
- **Cible**: Variable de sortie (y) que nous voulons prédire
- **Division train/test**: Diviser les données pour évaluer la performance du modèle
- **Classification**: Prédire des catégories (ex: oui/non, A/B/C)
- **Régression**: Prédire des valeurs continues (ex: prix, températures)
- **Précision**: Fréquence à laquelle le modèle fait des prédictions correctes
- **Validation croisée**: Méthode robuste pour évaluer la performance du modèle
